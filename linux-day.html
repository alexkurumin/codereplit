POR QUE 25 DE AGOSTO

A data marca o anúncio, não o código

A data celebra o dia em que Linus Torvalds anunciou publicamente seu projeto — não o lançamento do código, que só viria semanas depois. Foi o gesto de abrir o trabalho para outras pessoas que deu início a tudo.

Desde então, o kernel Linux deixou de ser um projeto pessoal para se tornar a base de Android, servidores web, supercomputadores e sistemas embarcados em praticamente todo o planeta — mantido por milhares de pessoas, em um ciclo de lançamentos que se repete a cada 9 a 10 semanas.

A cronologia do kernel

Do "hobby" de 1991 até a versão em desenvolvimento hoje — os marcos que definiram o Linux como o conhecemos.

a1e9f3cv0.0125 ago 1991

O anúncio no comp.os.minix

Linus Torvalds descreve seu sistema como um "hobby" que "não vai ser grande nem profissional como o GNU" — e pergunta o que as pessoas gostariam de ver em um Minix livre.

6c2a081v0.02out 1991

O código sai do computador de Linus

As primeiras linhas do kernel são disponibilizadas via FTP. Ainda dependia de ferramentas do projeto Minix para funcionar.

4f7b920v0.121992

Linux adota a licença GPL

Torvalds relicencia o kernel sob a GNU General Public License, garantindo que o código permaneça livre e aberto para sempre.

9de441av1.014 mar 1994

Primeira versão "estável"

Depois de quase três anos de desenvolvimento, o kernel recebe seu primeiro número de versão considerado maduro para uso geral.

2b8f015v2.01996

Suporte a multiprocessamento e a chegada do Tux

O kernel ganha suporte a SMP (múltiplos processadores) e o pinguim Tux, criado por Larry Ewing, é adotado como mascote oficial do projeto.

e15d908v2.62003

Novo modelo de desenvolvimento

A série 2.6 introduz um ciclo de lançamentos contínuo, sem os antigos ramos "estável" e "instável" separados — modelo que evoluiu para o atual.

5f30ac1git init2005

Linus cria o Git

Sem uma ferramenta de controle de versão que atendesse à escala do projeto, Torvalds escreve o Git em poucas semanas — hoje o sistema de versionamento mais usado do mundo.

c894e02v3.02011

20 anos de kernel

Para celebrar a data, Linus simplifica o esquema de numeração de versões, encerrando a era 2.6.x.

819d0f6v4.02015

Patches "ao vivo"

O recurso de live patching permite aplicar correções de segurança críticas sem precisar reiniciar o sistema — essencial para servidores em produção.

3ba1177v5.02019

Um projeto gigantesco

Décadas de contribuições acumuladas fazem do Linux um dos maiores projetos de software colaborativo já criados, mantido por uma comunidade global.

0e7c422v6.02022

Rust entra no kernel

Pela primeira vez, uma linguagem além de C e Assembly passa a ser aceita oficialmente para o desenvolvimento de drivers — um dos maiores debates técnicos da década.

b52f9d0v6.12 LTS2024

Suporte de longo prazo consolidado

Nova versão LTS chega com o suporte a Rust cada vez mais maduro para drivers e subsistemas do kernel.

f1a08e3v7.02026

Kernel chega à versão 7

O desenvolvimento mainline avança para a série 7.x, mantendo o ritmo de um novo lançamento a cada 9–10 semanas.

Números e fatos do kernel

Alguns fatos que dão a dimensão do que aquele "hobby" de 1991 se tornou.

9-10

semanas por versão

É o intervalo médio entre um lançamento mainline e o próximo — um ritmo constante mantido há mais de duas décadas.

100%

dos supercomputadores TOP500

Praticamente todos os supercomputadores mais rápidos do mundo rodam alguma distribuição Linux.

1996

o ano do Tux

O pinguim foi desenhado por Larry Ewing e escolhido em concurso como mascote oficial do projeto.

C

a linguagem original

Escrito majoritariamente em C e Assembly desde o início; Rust se juntou ao time oficialmente em 2022.

Git

criado pelo próprio Linus

Em 2005, sem ferramenta à altura do projeto, Torvalds escreveu o Git — hoje padrão de versionamento no mundo todo.

∞

onde ele roda

De relógios inteligentes e roteadores até Android, servidores web e a Estação Espacial Internacional.
